**Months 9–12: Portfolio + Job Hunt**

### 3. Portfolio Projects That Will Make You Stand Out (Leverage Your Mobile Background)
Recruiters want **production thinking**, not toy notebooks. Build these and deploy them (Streamlit/FastAPI + Vercel/Hugging Face Spaces or cloud):

1. **AI-Powered Mobile Feature (your superpower)** – On-device image classification or object detection app (TensorFlow Lite / Core ML / MediaPipe). Show how you optimised for mobile constraints.
2. **RAG Chatbot (“Ask My Docs” or company knowledge base)** – Most in-demand project in 2026. Use vector DB (Pinecone/Chroma), hybrid search, and evaluation metrics.
3. **Multi-Agent Workflow** – E.g., an AI research agent that uses tools (search, calculator, code interpreter) to complete a task end-to-end.
4. **LLM-Powered Mobile Backend Service** – Backend API that powers smart features in a mobile app (recommendations, smart replies, summarisation). Deploy with FastAPI + cloud.
5. **Production ML Pipeline** – End-to-end: data → training → evaluation → deployment + monitoring (include A/B testing or drift detection).

Host everything on GitHub with excellent READMEs (architecture diagrams, metrics, lessons learned). This is what gets you past ATS and recruiter screens.
